Algumas respostas
para começar.

O Horizonte Residencial é um empreendimento real?＋

Não. O Horizonte Residencial é um projeto conceitual criado para portfólio. Não representa uma oferta imobiliária real.

As plantas e metragens são definitivas?＋

Não. As opções de 92 m² e 124 m² e seus desenhos são demonstrativos. Não substituem plantas técnicas, documentos ou informações de um empreendimento real.

Como posso conhecer a proposta?＋

Você pode iniciar uma conversa pelo WhatsApp. A mensagem identifica o Horizonte Residencial como projeto conceitual para portfólio.

O formulário envia meus dados?＋

Ao enviar, o site abre o WhatsApp com seu nome e a planta escolhida em uma mensagem pronta. Nada é enviado automaticamente; revise e envie a mensagem pelo WhatsApp se quiser continuar.
